# **Business Operations Crisis Response** 

## **Overview** 

This repo contains my response to the simulated quarter end business operation crisis involving 3 simultaneous incidents. 

1. Enterprise contract provisional failure. 

2. Nationwide 3PL fulfillment outage affecting 1200+ orders. 

3. Vendor payment data corruption. 

## **Approach** 

So I approached the scenario as a parallel incident management problem rather than handling the issue strictly one at a time. The response focusses on: 

- Risk based triage 

- Clear Ownership 

- Immediate containment 

- Cross functional communication 

- Customer impact mitigation 

- Process improvement 

## **Key Decision** 

For the enterprise contract, I would not bypass the mandatory 24hour compliance and data privacy audit simply to meet the quarter end deadline. Instead, I would pursue all available compliant recovery paths while escalating the accounting treatment question to finance. So, it gets decided today EOD. 

I also propose a process improvement so that we can outline these edge case scenarios and handle them more efficiently in the future.
